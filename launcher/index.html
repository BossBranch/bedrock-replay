      Параметры

      Горячие клавиши Включает горячие клавиши для управления просмотром. Не работают при слежке за собой.

      Нажимайте эти клавиши в режиме просмотра, чтобы управлять записью.

      1 пауза · 2–4 скорость · 5/6 перемотка · 7 след. игрок · 8 рестарт

      Автозапись Начинает писать сразу при входе на LIVE, без команды .start
      Сохранять при выходе Если выйти из игры без .stop — запись всё равно сохранится
      Имена игроков Показывать ники других игроков над головой при просмотре
      Показывать чат при просмотре Во время реплея показывает сохранённые сообщения
      Показывать боковую панель Таблица очков / список сбоку экрана из записи
      Звуки записи Воспроизводит звуки мира из реплея
      Пауза после перемотки / рестарта После ±N / .seek / .restart ставить на паузу (по умолчанию нет)
