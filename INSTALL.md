# Установка Bedrock Server Replay (Windows)

## Для друга (пользователь)

1. Скачай / получи файл **`Bedrock-Server-Replay-Setup.exe`**
2. Запусти его (двойной клик)
3. Дождись установки — появится ярлык **Bedrock Server Replay**
4. Открой ярлык → в лаунчере настрой сервер и версию → **Запустить**

Node.js ставить не нужно. Интернет для установки не обязателен.

Данные (настройки и реплеи) лежат здесь:

`%APPDATA%\BedrockServerReplay\`

Удаление программы **не** стирает эту папку — после новой установки реплеи остаются.

Логи (если что-то сломалось — скинь эту папку):

`%APPDATA%\BedrockServerReplay\logs\`  
(`launcher.log`, `hub-ГГГГ-ММ-ДД.log`)

---

## Для тебя (сборка установщика)

На своём ПК, в корне проекта:

```bat
npm run dist
```

Готовый файл:

`launcher\dist\Bedrock-Server-Replay-Setup.exe`

Его и скидывай. Сборка тяжёлая (Electron + зависимости) — это нормально.
